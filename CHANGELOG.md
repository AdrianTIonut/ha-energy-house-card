# Changelog

## 0.1.0 (first publication)
- Card `energy-house-card` (also available as `energie-casa-card`): header, tiles, graph (24 h / 7 days), flow diagram, consumers, battery panel, inverters, statistics, editable prices, compact flow and compact statistics.
- **Visual editor** for the whole configuration (entity pickers, consumer list, look), with *Detect sensors automatically*.
- Battery runtime with reserve and shutdown levels (from entities or fixed values) and the backup runtime when the grid is gone.
- 18 test files, no dependencies.
